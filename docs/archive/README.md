# Archivo histórico

Todo lo que hay aquí es **material histórico o superado, no es fuente de verdad**. Se conserva por referencia (contexto de decisiones pasadas, demos, migraciones ya completadas) pero no debe usarse para entender el estado actual del proyecto. Para eso, ve al [índice de documentación](../README.md).

| Carpeta | Contenido |
|---|---|
| `demo/` | Runbook e implementación de un demo/pitch puntual ("Veltur"), ya realizado. |
| `aspirational-architecture/` | Propuesta de arquitectura (NestJS, Mapbox, Isar, WebRTC) que nunca se implementó — **contradice** el stack real descrito en [`03-ARQUITECTURA_FRONTEND.md`](../03-ARQUITECTURA_FRONTEND.md) y [`05-ARQUITECTURA_BACKEND.md`](../05-ARQUITECTURA_BACKEND.md), que son la fuente de verdad. |
| `superseded-requirements/` | Drafts tempranos de requerimientos (Anexos) ya reemplazados por las user stories estructuradas en `docs/product_requirements/`, más una copia duplicada de esas mismas user stories que vivía en la raíz del repo. |
| `frontend-iterations/` | Planes de migración e iteración del frontend Flutter ya completados, más mockups HTML de diseño. |
| `releases/` | Notas de release puntuales (ej. `RELEASE_v0.1.0-alpha.md`). |
